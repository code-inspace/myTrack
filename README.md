# MyTrack — Full-Stack PWA

Production-ready PWA pour le suivi d'habitudes, tâches quotidiennes, objectifs, sommeil et notifications push.

## 🌐 Déploiement en Ligne (Vercel)

👉 **Production URL** : [https://mytrack-nine.vercel.app](https://mytrack-nine.vercel.app)

---

## 📱 Installation PWA sur iPhone / Android

1. Ouvre **[https://mytrack-nine.vercel.app](https://mytrack-nine.vercel.app)** sur ton navigateur mobile (Safari sur iOS ou Chrome sur Android).
2. Touche le bouton de partage **Partager (carré avec flèche vers le haut)** puis **"Sur l'écran d'accueil"**.
3. L'application s'ouvre en plein écran comme une application native !

---

## 🔑 Comptes & Authentification

- **Compte Démo** : `demo@de.mo` / `demo` (Données réelles hébergées sur Supabase PostgreSQL).
- **Compte Vierge** : Crée un compte avec ton propre email pour démarrer avec un compte vide et personnalisé.

---

## 🛠️ Stack Technique

- **Framework** : Next.js 16 (App Router & Turbopack)
- **Base de Données** : PostgreSQL via Supabase & Prisma ORM
- **State & Cache** : TanStack Query v5
- **Notifications Push** : OneSignal Web SDK
- **Styling** : TailwindCSS (Thème sombre `#111214`, accent `#D4F63D`)
- **Intelligence** : Moteur Heuristique & Connecteur IA
